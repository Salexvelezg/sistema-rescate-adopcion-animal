\# 1. Introducción



El presente proyecto consiste en el diseño de un Sistema de Control de Rescate y Adopción Animal, cuyo propósito es facilitar la gestión de reportes de animales en situación de abandono, peligro o maltrato, así como organizar los procesos de rescate, atención veterinaria y adopción responsable.



El sistema permitirá registrar los casos reportados, realizar el seguimiento del estado de cada animal, asignar voluntarios, almacenar información sobre las atenciones veterinarias y gestionar solicitudes de adopción.



Para representar la solución se utilizarán diagramas UML, patrones de diseño y el modelo de desarrollo Gitflow. Estas herramientas permitirán organizar la arquitectura del sistema, representar las interacciones entre sus componentes y mantener un control ordenado de las versiones del proyecto.



\## 1.1 Objetivo general



Diseñar un sistema informático que permita gestionar de manera organizada los procesos de rescate, atención y adopción animal, facilitando el seguimiento de cada caso y la coordinación entre los usuarios involucrados.



\## 1.2 Objetivos específicos



\- Identificar los actores y requisitos funcionales y no funcionales del sistema.

\- Representar la estructura y el comportamiento del sistema mediante diagramas UML.

\- Aplicar patrones de diseño como Singleton, Observer y Factory Method.

\- Organizar el desarrollo del proyecto mediante Git y la estrategia de ramas Gitflow.

\- Facilitar el seguimiento de los casos y la gestión de solicitudes de adopción.
