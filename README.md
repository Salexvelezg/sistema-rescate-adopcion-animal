# Sistema de Control de Rescate y Adopción Animal

## Descripción del proyecto

Este proyecto consiste en el diseño de un sistema informático para gestionar el rescate, la atención veterinaria y la adopción responsable de animales. Busca organizar la información de los casos, facilitar la asignación de voluntarios y dar seguimiento al proceso de adopción.

## Objetivo general

Diseñar un sistema que permita organizar y controlar los procesos de rescate y adopción animal mediante requisitos definidos, diagramas UML y patrones de diseño de software.

## Objetivos específicos

- Identificar el problema y definir los requisitos funcionales y no funcionales.
- Representar la estructura y el comportamiento del sistema mediante diagramas UML.
- Documentar patrones de diseño aplicables al sistema.
- Utilizar Git y GitHub para gestionar versiones y organizar el trabajo mediante Gitflow.

## Patrones de diseño documentados

- **Singleton:** centraliza la gestión de casos.
- **Observer:** permite notificar cambios a los interesados.
- **Factory Method:** facilita la creación de expedientes según el tipo de animal.
- **MVC:** organiza la aplicación en modelo, vista y controlador.

## Control de versiones

Se utiliza Gitflow con las siguientes ramas:

- `main`: versión estable del proyecto.
- `develop`: integración de los avances.
- `feature/documentacion`: desarrollo de la documentación y los diagramas.

## Estado del proyecto

Actualmente se encuentra en la fase de diseño y documentación. Los requisitos, patrones de diseño y diagramas UML están documentados.
